## Skill: research orchestration

Build an evidence graph, not a pile of search results. Every research pass should increase coverage, resolve a gap, or test a hypothesis.

For each pass:
- Split independent source classes or entities into parallel branches and merge only their evidence records.
- Record the path query -> source -> link/citation/artifact -> observation -> claim -> entity/relationship.
- Follow rare named leads, documents, aliases, dates, handles and visual details until they resolve or become explicit gaps.
- Prefer targeted searches with distinct source classes over repeating one broad query.
- Re-check high-impact findings against a primary record or independent source and actively seek counter-evidence.
- Keep discovery hints, observations, inferences and verified claims as separate states.

Run a coverage review before each replan: languages, primary sources, independent sources, archives, documents, code, registries, public social material and media.
Stop only when the current mode's deadline/budget is reached or remaining gaps have low expected information gain; never stop merely because a plausible summary is available.
