# Changelog

## 0.1.0 — Stage 1

Initial open-source foundation:

- Textual full-screen TUI and Typer CLI;
- iterative planning/re-planning;
- SearXNG/DDGS search abstraction;
- OpenAI-compatible optional LLM adapter;
- SQLite durable runs/plans/queries/sources/snapshots/events;
- complete search-result provenance;
- bounded public HTTP/HTML fetcher;
- source snapshot storage;
- resume and Markdown/JSON export;
- tests, smoke test and CI.
